## Overall Impression

视觉识别度在工建 SaaS 赛道属头部水准（对标 Oracle Aconex 工程档案语言 + Autodesk Build 仪表板密度），基础体验层（加载反馈、错误提示、一致性、极简美学）已达 Good。真正的短板集中在**效率工具层**：零快捷键、零批量操作、零帮助系统——这三项决定了高频用户（项目经理/财务审批人，日均 50+ 次表单与审批）的长期留存。最大机会：把"好看的工业界面"升级为"高效的工业控制台"。

## What's Working

1. **工业化视觉签名成体系**：蓝图角标 + Hazard 条纹 + 石墨黑侧栏形成强记忆点，竞品多为浅灰底圆角卡片蓝系，本产品一眼可辨。
2. **真实接口流程严谨**：表单字段与后端 DTO 严格对齐；错误态显式提示 + 重试入口，无静默 fallback；逾期质保金卡片受 `finance:view` 权限保护，无权限角色不渲染不发请求，避免必然 403。
3. **暗色模式镜像完善 + Element Plus 深度定制**：light.css → dark.css 全变量重定义（sidebar #101214 → #23262c，文字反转 #f2f3f1）；覆盖旋转方块 spinner、条纹行底色、方形页码，非原生开箱。

## Priority Issues

- **[P1] 快捷键体系完全缺失**
  - Why it matters: 项目经理/财务审批人日均 50+ 次提交与审批，纯鼠标交互造成累积性挫败；144 个组件中未检出任何键盘加速器。
  - Fix: Phase 1 实现 Ctrl+S 保存 / Enter 提交 / Esc 关闭弹窗抽屉 / `/` 聚焦全局搜索；Phase 2 表格 ↑↓ + Enter 行级导航；Phase 3 自定义快捷键面板。
  - Suggested command: `/impeccable adapt`

- **[P1] 帮助文档与内嵌引导零存在**
  - Why it matters: 新人不理解"BLOCK 预算拦截""质保金逾期""垫资"；错误消息"接口未返回数据"无法指导行动；培训成本转嫁实施团队。
  - Fix: 新增 HelpCenter 路由：新手引导 Modal（首次登录三步高亮）+ 字段说明 Tooltip（业务定义）+ 错误码字典（Message 右上角入口）+ 快捷键帮助页 `/help`。
  - Suggested command: `/impeccable onboard`

- **[P2] 批量操作缺失增加重复劳动**
  - Why it matters: 财务月审批 200+ 笔付款申请需逐个点击查看提交；项目管理员删除 50+ 草稿需逐个点击；违反 SaaS 效率基准。
  - Fix: 表格左上增"批量操作"下拉：批量删除（多选 + 二次确认）/ 批量提交（过滤草稿态）/ 批量导出 xlsx / 状态批量变更（限草稿与已驳回）。
  - Suggested command: `/impeccable adapt`

- **[P2] 硬编码颜色泄漏 446 处污染令牌系统**
  - Why it matters: 破坏 token 一致性与暗色模式可维护性；未来换肤需人工全量替换。集中于 budget/cost-account(18)、labor/salary/stats(17)、material/inbound(11)、finance/settlement/detail(11)。
  - Fix: 分批替换为 `--zw-*` 变量；优先级 表单字段 > ECharts option > element-override SCSS。
  - Suggested command: `/impeccable harden`

- **[P2] 错误恢复机制不完整**
  - Why it matters: 连续失败后用户盲目重试；无"上报 IT"路径；网络恢复无自动重试。
  - Fix: localStorage 记录失败计数，≥3 次升级顶栏 Hazard 条告警；错误态增"上报问题"（预填 error_code + request_id）；网络恢复后自动重试最近失败接口。
  - Suggested command: `/impeccable harden`

- **[P3] 固定像素宽度 179 处破坏响应式**
  - Why it matters: ≤992px 断侧栏后表格横向溢出；统计卡 4 列 grid 未降级；图表容器未重排导致 tooltip 遮挡。集中于 contract/output-report(8)、material/stock(6)、login/index(5)。
  - Fix: 汉堡菜单 drawer + grid `repeat(2,1fr)` 移动态 + 图表 resize 监听重算宽度。
  - Suggested command: `/impeccable adapt`

## Persona Red Flags

**Alex (Power User)**：全文未检出任何键盘快捷键（无 `/` 聚焦搜索、无 Esc 关闭弹窗）；付款申请新增流程需 7+ 次点击且含远程加载等待；项目列表无批量删除/提交/导出，财务审批无批量通过 → 高流失风险。

**Jordan (First-Timer)**：术语无解释（"BLOCK 拦截""质保金逾期""垫资"悬停无 Tooltip）；错误消息技术化（"接口异常""接口未返回数据"）；空状态文案尚可（"暂无合同——从立项开始创建"给方向不道歉）。

**Sam (Accessibility)**：`:focus-visible` 全局定义统一焦点环 ✅；对比度达标（#14161a vs #f6f7f5 = 16.8:1，橙按钮 vs 深字 5.3:1）✅；`outline: none` 零出现 ✅；顶栏消息/主题切换仅图标 + tooltip，纯键盘用户难辨用途；`prefers-reduced-motion` 仅 1 处全局声明，逾期脉冲动画覆盖不足。

## Minor Observations

1. Token 命名一致性极佳：`--zw-radius-xs/sm/md/lg` 与 `--zw-space-*` 层级分明，未见 `margin-left: 17px` 类任意值泄漏。
2. 图表性能优化到位：ECharts 实例缓存 `lastPieOverview`；主题切换 `watch isDark` 重绘 option 而非重发 API，省 2× 请求延迟。
3. 资金计划曲线双 Y 轴设计合理：左轴万元应付预测（柱形）、右轴申请笔数（折线），业务维度分离清晰。
4. 表单远程加载摩擦：项目选择器 `remote-method` 每输入 3 字符即触发 GET `/v1/project/list`，高并发压力大，建议节流 + 本地历史词缓存。
5. `workflow/process/index.vue:43` 的 `<el-image>` 缺 alt/aria-label（login/index.vue:39 验证码图已有 `alt="验证码"`）。
6. `will-change` 全局仅 1 处，且与 width transition 配对出现（应随动画结束移除或改用 transform）。
