# 前端资产方案：插画与图片（待补齐清单 + 生产规格）

> 2026-10-05 盘点：系统已有 86 张图片资产（favicon 全套 / 双租户 logo / 登录 hero+视频背景 / 403/404 错误页 / empty-blueprint 空态）。本文只列**缺口**与补齐方式。配套的非图片类资产（骨架屏/翻牌/话术/打印版式/品牌主色/画廊页）已随代码落地，画廊页 `/dev/gallery` 可视化全部既有资产。

## 一、统一风格规范（所有新插画必须遵守）

| 项 | 规格 |
|---|---|
| 风格 | 与 `empty-blueprint.png` 一致：**工程蓝图线条风**——细线描边 + 中性灰阶 + 品牌橙作唯一点缀色，扁平无渐变阴影 |
| 线条色 | `--zw-text-quaternary`（中性灰），点缀用 `#ff6b00`（注意：若启用品牌主色换肤，插画内的橙色不改——插画不是换肤面，保持中性即可） |
| 尺寸 | 场景插画 480×360（4:3）、装饰性 spot 240×180；导出 2x（即源文件 960×720）保证 retina |
| 格式 | PNG（透明底）为主；面积大的场景图可选 SVG（线条风天然适合矢量） |
| 命名 | `src/assets/illustrations/<场景>-<状态>.png`，如 `empty-settlement.png`、`empty-search.png` |
| 明暗 | 每张两版：`*.png`（浅底）+ `*-dark.png`（深底，线条用 rgba(255,255,255,.38)）——与既有 err-403/404 双版惯例一致 |
| 接入 | 通过 `ZwEmptyState` 的 `#image` slot 注入（组件已支持，无需改造） |

**生产方式（按成本从低到高）**：① AI 生成底稿 + 手工按上述色板修线（推荐，empty-blueprint 即此流程）；② 设计师按规范手绘；③ 先用图标级占位（`ZwEmptyState` 默认态）不等插画。
