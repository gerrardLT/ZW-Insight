# 术语表（业务命名基准）

> 建立日期：2026-10-18 ｜ 最近修订：2026-10-19（全面工程化下沉与二级分类重整）
> 维护规则：本文件与 `zw-insight-web/src/constants/biz-labels.ts` 是全站命名的**唯一基准**；菜单名、页面标题、状态标签、金额列名必须与本文一致。
> 校验：`cd zw-insight-web && npm run check:labels`（warn-only，命中禁用词即列出）。
> 背景：对标中经优采与中国施工企业现场、商务、财务真实工作语言深度收敛。

## 一、命名四规范

1. **菜单 = 单据/台账名词（真实工程习惯）**，不带动词、不带抽象IT词汇：材料入库单、现场领料单、工程付款申请、工程竣工结算、应收工程账款台账。
2. **金额字段 = 方向 + 口径 + 累计**：累计回款、累计付款（审批）、累计付款（现金）、应付未付、审批中冻结金额。严禁子项出现与工程重名的“项目名称”，严禁裸词“总收入/总支出”。
3. **状态 = 施工阶段与合同状态真实词**：投标中（非"招标中"）、在建（非"施工中"）、停工（非"已暂停"）、已结项（非"已关闭"）。
4. **对手方 = 建设单位（发包人）/ 施工单位（承包人）/ 施工班组 / 供应商**，严禁使用“施工队伍”、“业主单位（口语）”、“签约公司”等生硬词汇。

## 五、金额口径与核心指标字典

| 指标词汇 | 真实工程含义 | 数据源与计算逻辑 |
|---|---|---|
| **签约合同价** | 施工总承包合同最初签署的含税总价 | `biz_construction_contract.contract_amount` |
| **已确认签证** | 现场办理并由监理/发包人确认的变更签证额 | `cumulative_change_amount` |
| **完成产值** | 现场实际完成并申报核实的工作量金额 | `cumulative_output` |
| **已收工程款** | 实际银行进账并核销的项目回款 | `cumulative_received_amount` |
| **工程款未收金额** | 甲方当前欠发承包人的工程款余额 | `(签约合同价 + 签证金额) - 累计已收款` |
| **已付总支出** | 该项目名下已向分包/供应商实际支付的款项 | `biz_project.total_expense`（审批） / `pay_status=PAID`（现金） |
| **应付未付欠款** | 五大支出合同已结算但未实际支付的欠款总额 | `biz_payable` OPEN 余额合计 |
| **审批中冻结金额** | 提交且正在流程中尚未划拨的在途付款申请 | `SUM(payment_amount WHERE status='SUBMITTED')` |
| **实际净现金结余** | 截至当前该项目是正向造血还是垫资失血 | `银行累计实收款 - 银行累计实付款` |
| **预计结算利润** | 完工后预计能拿到的净收益 | `(合同价 + 签证) - CBS预计总成本(EAC)` |
| **当前项目垫资** | 项目占用公司自有资金净额 | `MAX(0, 实际支出流出 - 实际回款流入)` |

## 六、全站禁用词清单（`npm run check:labels` 严格扫描）

以下词汇在业务视图中严禁出现，凡出现必提示整改：
1. `项目报备`（改用：`项目台账` 或 `工程立项`）
2. `施工中`（改用：`在建`）
3. `已暂停`（改用：`停工`）
4. `已关闭`（改用：`已结项`）
5. `招标中`（改用：`投标中`）
6. `已中标`（改用：`待开工`）
7. `已落标`（改用：`未中标`）
8. `账户名称`（在CBS成本树中禁用，改用：`成本科目名称`）
9. `费用类别`（在成本与预算中禁用，改用：`成本类别` 或 `成本科目`）
10. `在途占用` / `申请中(在途)`（改用：`审批中冻结金额`）
11. `落袋利润`（改用：`实际净现金结余`）
12. `结算单ID` / `结算单号`（统一改用：`结算单编号`）
13. `施工队伍`（改用：`施工班组`）
14. 子表中的 `项目名称`（改用：`分项工程名称` / `物料名称` / `清单名称`）
15. `项目ID（空=公司整体）`（改用：`所属工程项目（留空代表公司总部）`）
