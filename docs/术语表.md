# 术语表（业务命名基准）

> 建立日期：2026-10-18 ｜ 维护规则：本文件与 `zw-insight-web/src/constants/biz-labels.ts` 是全站命名的**唯一基准**；菜单名、页面标题、状态标签、金额列名必须与本文一致。新增单据/状态/菜单先改本文与常量层，再写页面。
> 校验：`cd zw-insight-web && npm run check:labels`（warn-only，命中禁用词即列出）。
> 背景：三轮对标中经优采后的术语收敛（spec：`.kiro/specs/finance-clarity-terminology-ui/`）。

## 一、命名四规范

1. **菜单 = 单据/台账名词**（对象名），不带动词、不带"管理"后缀：入库单、领料单、付款申请、竣工结算、应收账款台账。
2. **金额字段 = 方向 + 口径 + 累计**：累计回款、累计付款（审批）、累计付款（现金）、应付未付、在途申请。禁止裸词"总收入/总支出/预算金额"。
3. **状态 = 业务里程碑词**，承包人视角：投标中（非"招标中"）、在建（非"施工中"）、停工（非"已暂停"）、已结项（非"已关闭"）。
4. **对手方 = 甲方/乙方、收款方/付款方、供应商/分包方**，一处一义；列表列统一"收款方"（支出侧）/"付款方"（收入侧）。

## 六、单据编号规范

- 列表列名统一 **"结算单编号"**（禁用"结算单号/结算单ID"混用；分包结算禁止展示数据库 ID）。
- 单号一律由 serial_number_rule 生成；新增规则键：`SUBCONTRACT_SETTLEMENT`（前缀 FBJS）。
- 编号列展示规则生成的单号；无单号的存量按 id 顺序回填。

## 八、禁用词清单（check-labels 扫描项）

`施工中` `已暂停` `已关闭`（状态语境）`招标中` `已报备` `已中标` `已落标`（项目状态语境）`账户名称`（CBS 语境）`费用类别`（成本语境）`结算单ID` `结算单号`（统一"结算单编号"）`总收入` `总支出` `其他总支付`（列表列名）`回款金额` 与 `收款金额` 混用（业务页统一"回款"）`未支付` `已支付`（统一"未付/已付"）
