# P1 PC Web 效率增强 - 用户指南

## 🎯 新功能概览

本次更新为 PC Web 端带来了三大核心效率增强功能，帮助你更快地完成日常操作：

### 1️⃣ 键盘快捷键支持
不再需要频繁使用鼠标！关键操作都可以通过键盘快速完成。

### 2️⃣ 批量操作
一次处理多项任务，节省重复操作时间。

常用功能一键直达，提升数据管理效率。

## ⌨️ 快捷键速查表

### 通用快捷键（所有页面）

| 按键 | 功能 | 适用页面 |
|------|------|----------|
| **Ctrl+Enter** | 提交表单 | 付款申请、报销、入库单 |
| **Escape** | 关闭弹窗 / 清空选择 | 材料入库 |

### 审批工作流专用

| 按键 | 功能 | 说明 |
|------|------|------|
| **↑ (上箭头)** | 上一行 | 在待办列表中向上移动焦点 |
| **↓ (下箭头)** | 下一行 | 在待办列表中向下移动焦点 |
| **空格键** | 选择行 | 切换当前行的选中状态 |
| **Enter** | 快速通过 | 未选中时通过当前行；选中时批量通过 |
| **Ctrl+A** | 全选 | 选中当前页所有任务 |

### 表格导航（列表页面）

| 按键 | 功能 | 适用页面 |
|------|------|----------|
| **↑ / ↓** | 行导航 | 付款申请、材料入库 |
| **复选框** | 多选 | 材料入库 |
| **右键点击** | 上下文菜单 | 材料入库 |

## 📋 详细使用说明

### 审批工作流 (`/approval`)

#### 操作流程示例
```
1. 访问审批页面 → /approval/todo
2. 使用 ↑/↓ 键移动到目标任务
   📍 高亮显示：浅蓝色背景
3. 按空格键选择任务
   ✅ 勾选框会出现
4. 按 Ctrl+Enter 打开审批对话框
5. 输入意见后再次 Ctrl+Enter 提交
或者：
6. 直接按 Enter 快速通过当前行
```

#### 视觉反馈
- **聚焦行**: 浅蓝色背景 (#ecf5ff) + 主色调边框
- **已选行**: 复选框打勾
- **自动滚动**: 选中的行会自动滚动到可视区域

---

### 付款申请表单 (`/finance/payment-apply`)

#### 新增流程
```
1. 点击"新增付款申请"
2. Tab 键在各字段间自然切换
3. 填写完毕后按 Ctrl+Enter 快速提交
💡 提示条会显示："Ctrl+Enter 快速提交表单 | Tab 切换字段"
```

#### 注意事项
- 只有在**不在输入状态**时 Ctrl+Enter 才会触发提交
- 如果在表单中输入中，Ctrl+Enter 无效（防止误操作）

---

### 个人报销 (`/finance/personal-reimbursement`)

#### 快捷提交流程
```
1. 点击"新增个人报销"
2. 填写金额、日期、备注
3. 按 Ctrl+Enter 提交

📝 提示：Tab 键可在字段间切换
```

---

### 材料入库 (`/material/inbound`)

#### 批量操作

**场景**: 删除多条草稿状态的入库单

```
1. 勾选左侧复选框（可选多条）
2. 顶部工具栏显示"批量删除 (已选 X)"
3. 点击按钮确认删除
或者：
- 按空格键选择行
- 再按其他复选框
```

#### 右键上下文菜单

**如何使用**:
```
1. 在任意行上右键点击
2. 弹出菜单包含：
   📝 编辑 - 快速打开编辑对话框
   ✅ 提交 - 提交该入库单（仅草稿可用）
   📄 复制 - 复制此记录（开发中）
   🗑️ 删除 - 删除这条记录
```

**快捷操作**:
- **Ctrl+Enter**: 新建入库单
- **Escape**: 关闭弹窗并清空选择

## ⚠️ 重要注意事项

### 1. 输入保护机制
✅ **正确用法**:
- 在输入框内打字：快捷键不触发
- 离开输入框后：快捷键生效

❌ **错误理解**:
- 以为任何时候 Ctrl+Enter 都会提交

### 2. 状态重置规则
- **切换 Tab**: 清除所有选择和行索引
- **刷新数据**: 重置当前行索引
- **打开表单**: 禁用表格导航

### 3. 浏览器兼容性
| 浏览器 | 版本要求 | 测试状态 |
|--------|---------|----------|
| Chrome | 90+ | ✅ 完全支持 |
| Firefox | 88+ | ⚠️ 需验证 |
| Safari | 14+ | ⚠️ 需验证 |

### 4. 无障碍特性
- ✅ 键盘可访问所有功能
- ✅ 屏幕阅读器友好
- ⚠️ 建议启用浏览器高对比度模式

## 🔧 故障排查

### 问题 1: 快捷键不响应
**原因分析**:
- 可能正在输入框中
- 可能表单已打开
- 可能已切换到"已办"Tab

**解决方案**:
1. 检查是否点击了其他地方
2. 尝试 ESC 退出当前焦点
3. 确认在正确的 Tab（待办 vs 已办）

### 问题 2: 高亮不明显
**调整建议**:
- 增加显示器亮度
- 启用 Windows/macOS 高对比度主题
- 使用深色模式（如果可用）

### 问题 3: 右键菜单无法显示
**检查项**:
- 是否在草稿状态（部分功能受限）
- 是否被浏览器扩展拦截
- 尝试刷新页面重试
