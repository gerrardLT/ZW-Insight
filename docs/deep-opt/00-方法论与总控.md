## 二、每模块六步法（深挖蓝图的生成流程）

1. **现状考古**（两路证据）
   - 代码考古：Controller/Service 全读，状态机与校验规则逐条列出；前端页面结构；DB schema 与索引
   - 数据考古：线上库真实分布——状态直方图、字段空置率、异常值、零使用功能（识别"摆设功能"）
2. **成熟度定位**：feature-ledger L0-L4 打分 + 八维缺口（复用 tools/feature-ledger，工具失效则手工按同口径评分并在蓝图注明）
3. **基准对照**：标杆产品功能树拆解（工程管理领域标杆）+ 行业规范条目映射 → 生成缺口矩阵（我们有/标杆有/规范要求有/实绩在用）
4. **领域建模**：事件风暴（命令-事件-聚合-不变量）→ 补全状态机（含驳回/撤回/作废/并发分支）→ 业务不变量清单（勾稽/权限/时序）
5. **ROI 分档**：缺口分三档——必须闭环（业务断裂/账实风险）、细节增强（有但粗糙）、锦上添花（标杆有我们可无）；每档列实现代价估计
6. **闭环验证**：模块级生命周期测试（仿 keys/lifecycle-sim-v2.sh 模式，租户 9999）+ 全量回归 + R7 审计不变量扩展 + 真实界面抽验
