# P0-A 水印真实性改造记录

- 实施日期：2026-09-14
- 修复模块：`zw-insight-app/src/pages/site/watermark-camera/index.vue`
- 测试用例：`zw-insight-app/tests/pages/watermark-camera.test.ts`

## 1. 痛点与真实性违例修复
1. **假水印嵌入问题**：
   - 之前代码在选择相机拍照后直接将原图 `originPath` 赋给 `previewImage`，并弹出“水印已自动嵌入”，实际根本没有调用离屏 Canvas 或 `watermarkCompositor.compose()`。
   - 修复后：读取原图实际尺寸动态调整离屏画布尺寸，真正调用 `watermarkCompositor.compose()` 完成四行文字与半透明背景压制，将返回的水印图片路径赋给 `previewImage`，提示“本地水印已合成”。
2. **默认人员身份问题**：
   - 之前代码在未登录时回退 `'现场施工员'`，属于伪造人员。
   - 修复后：读取当前登录人真实姓名/账号，若无身份信息，拦截拍照并提示“未获取到当前登录人员，请重新登录”。
3. **自动勾选项目问题**：
   - 之前代码在接口拉到列表时自动选择 `projects[0]` 填充，伪造了用户的主动确认。
   - 修复后：移除自动勾选逻辑，用户必须主动选择所属项目才可触发拍摄。
4. **法律与存证文案合规**：
   - 之前文案为“工程防伪影像”“防篡改水印层”“拍照存证”。
   - 修复后：规范文案为“中维智营 · 现场水印影像”“本地水印已合成”，不做未经验证的“防伪/防篡改”过度承诺。

## 2. 验证结果
- `tests/pages/watermark-camera.test.ts` 4/4 通过（覆盖未选项目拦截、未登录身份拦截、展示信息真实渲染、真实调用水印合成器并传递项目部位组合名称）。
