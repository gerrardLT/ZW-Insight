## 一、整体架构概览

```
┌─────────────────────────────────────────────────────────────────────┐
│                        ZW-Insight 工程项目管理平台                     │
├──────────────┬──────────────┬──────────────┬────────────────────────┤
│   PC 端       │   移动端      │  供应商门户   │       后端服务           │
│ (Vue3+TS+EP) │ (uni-app)    │ (Vue3+TS)    │ (Spring Boot 3.2/JDK21)│
├──────────────┴──────────────┴──────────────┴────────────────────────┤
│  MySQL 8.0  │  Redis 7  │  MinIO  │  RabbitMQ  │  Flowable 7.0      │
└─────────────────────────────────────────────────────────────────────┘
                              ↓
    ┌────────────────────────────────────────────────────────┐
    │  工程工具链：consistency-audit / feature-ledger         │
    │  测试体系：L1 单元 → L2 集成 → L3 API → L4 生命周期 → L5 E2E│
    │  CI/CD：deploy / codeql / security-scan / performance-k6│
    └────────────────────────────────────────────────────────┘
```

**核心机制（跨模块）**：

- **多租户隔离**：所有业务表 `tenant_id` + MyBatis-Plus 拦截器自动注入
- **数据权限**：项目级基于 `sys_user_project`，覆盖 23 个项目级 Mapper
- **预算硬控制**：`@BudgetCheck` AOP 拦截超预算操作（zw-budget）
- **金额闭环回写**：合同 → 预算 → 结算 → 付款，领域事件驱动累计值同步
- **级联删除事件**：`ProjectDeletedEvent` + 11 个 `*ProjectCascadeCleanupListener`（覆盖 69 张含 `project_id` 的表）
- **审批与回滚**：Flowable 7.0 + `ApprovalRollbackController`（对称回滚累计值）
- **数据脱敏**：`@Desensitize` 注解 + `DesensitizeSerializer`（zw-common）
- **审计追溯**：`SysAuditLog` + `AuditLogController`（zw-system）
- **乐观锁 + 逻辑删除**：`version` / `deleted` 字段全表覆盖

## 三、后端模块详情（22 个 Maven 模块）

### 3.1 通用基座

#### zw-common — 通用基座

- 统一响应 `R<T>` / 分页 `PageResult<T>` / 业务异常 `BusinessException`
- 基础实体 `BaseEntity`（id、tenant_id、create/update、deleted、version）
- 领域事件契约：`ProjectDeletedEvent`、`ChangeEventApprovedEvent`、`LoginLogEvent` 等（Published Language 模式，解决跨模块反向依赖）
- 数据脱敏：`@Desensitize` + `DesensitizeSerializer` + `DesensitizeType`（手机号/身份证/银行账号等）
- 通用工具类：`UserContext`（当前用户 + 租户 + 数据权限）、`TenantContext`
- 测试基座：`TestConstants`（`TEST_TENANT_ID = 9999L`）+ `TestDataCleaner`

#### zw-security — 认证安全

- JWT Token 登录/登出/刷新（jjwt 0.12.5）
- 密码 BCrypt 加密 + 强度校验
- 图形验证码（Redis 缓存 + 前端校验完整闭环）
- 短信验证码（`AliyunSmsService` + Redis 存储）
- IP 锁定机制（连续失败 → Redis 记录 → 锁定时长可配）
- 多租户 tenantCode 支持 + `TenantModuleInterceptor`（模块级开通校验）
- `@RequiresPermission` 注解 + `PermissionInterceptor`（接口级功能权限，高危接口已覆盖：system/*、project:delete、finance:payment:submit）

#### zw-system — 系统管理

- 机构管理（树形 CRUD + 启停用）
- 人员管理（分页 + CRUD + 分配角色 + 批量导入导出 + 批量启用停用）

- 菜单管理（树形 CRUD + 按钮权限 + 平台/普通菜单权重）
- 数据字典（分页 CRUD + 字典项树形）
- 岗位管理（分页 CRUD）
- 日志管理（操作日志 / 登录日志 / 异常日志 / **审计日志**）
- 系统配置（分组查询 / 批量更新 / 恢复默认）
- **多租户管理**（`SysTenantController`: CRUD + 启停用 + 续期 + 模块权限）
- **租户类型管理**（`SysTenantTypeController`: CRUD + 批量删除）
- **备份管理**（`BackupController`: 手动/定时备份 + 备份记录 + 恢复）

- **打印模板管理**（在 zw-file，见 3.4）

#### zw-message — 消息通知
