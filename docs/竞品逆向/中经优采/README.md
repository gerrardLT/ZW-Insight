## 二、核心结论速览

### 2.1 竞品在"采购寻源"域对 ZW-Insight 形成代差

| 能力 | 中经优采 | ZW-Insight |
|---|---|---|
| **多轮竞价（反向拍卖）** | ✅ 竞价/拍卖 + **起拍价 + 价格梯度 + 最小报价单位数** + 按物料/按总价 | ❌ 无 |
| **密封报价** | ✅ **开标密码 + 报价解密时间** | ❌ 无 |
| **多轮询价** | ✅ **二轮询价**（一轮/二轮报价分区） | ❌ 单轮 |
| **招标节点工作流** | ✅ **12 节点**（招标计划→…→中标通知）含用时统计 | ⚠️ 招标能力在投标模块，非采购方寻源 |
| **双决标方式** | ✅ **专家决标 / 价格决标** + 技术/商务评分项可配置 | ⚠️ 仅评标排名 |
| **保证金/报名费闸门** | ✅ 报名费+保证金必填 + 凭证上传 + 待审核 | ⚠️ 有 `biz_security_bond`，无闸门 |
| **报价要求开关组** | ✅ 6 项开关（含税/含运费/部分报价/落地价/要上传投标文件/录品牌） | ❌ 无 |
| **代报价** | ✅ 采购方代录（**须补审计**） | ❌ 无 |

### 2.2 ZW-Insight 在"经营分析与资金治理"域明显领先

| 能力 | ZW-Insight | 中经优采 |
|---|---|---|
| **滚动资金预测 + 逾期未付单列** | ✅ `overdue_unpaid` 构成项 | ❌ 未发现 |
| **CBS 流水恒等守卫 + 自动归集对账** | ✅ `delta` + `balance_after` + 幂等键 + 每日 02:30 | ❌ 仅人工台账+人工核实 |
| **项目删除级联（69 表）** | ✅ 事件 + 11 模块 Listener | ⚠️ 未发现 |
| **防自审 + 转办防绕道** | ✅ 审批引擎硬校验 | ⚠️ 未发现 |
| **统一编号规则** | ✅ `serial_number_rule` | ❌ 规则不统一且可手改 |
| **状态标签色义** | ✅ 状态×操作矩阵 | ❌ 仅 3 色，12 节点同色 |
| **银行流水勾稽 + 票据/融资/质保金** | ✅ 完整台账 | ⚠️ 未见流水勾稽 |

### 2.3 只做一件事 / 只做一个方向

- **只做一件事**：付款申请**订单级三段占用**（已申请 / **申请中** / 可申请）+ 可申请余额**硬拦截**。成本低、风险低、审计价值高，是资金内控的直接差距。
- **只做一个方向**：**多轮竞价 + 密封解密 + 二轮报价**。这是竞品唯一形成代差的能力，也是 ZW-Insight 采购模块从"询比价"升级为"电子招采平台"的跳板。

### 2.4 经营分析层（`07` 卷补充，02/03 卷未覆盖）

02/03 卷只写到**单据层**（付款申请、收款登记的字段与流转）。本产品的**分析与经营层**是独立的一层，包含：

| 层 | 内容 | 可借鉴点 |
|---|---|---|
| 项目 360 经营卡片 | 10 个模块；**实际成本卡与实付成本卡同屏并列**（利润率 17.3% vs 现金利润率 84.2%） | 双口径同屏并列 |
| 项目级经营看板 | **14 个子页**（6 成本页与 6 类预算一一对应 + 8 资金页） | 成本页与预算分类严格对齐 |
| 三维经营分析台账 | 项目/供应商/客户 三维 × **64/25/16 列**，每指标均为 `{divisor, dividend, rate}` | **指标三元组下发**（低成本、杜绝分母口径不一致） |
| 合同执行汇总 | `/analyse/contract/execute/total`：全公司 `unRecordAmount` = **应收 1,070 万 / 应付 558 万** | 应收应付单一事实源 |
| **额度四段占用** | 付款侧 `已申请/申请中/可申请`；**开票侧 `已开票/开票中/可开票`**（同构复用） | **统一"总量−已占用−在途=可用"范式** |
| 资金账户与支付中心 | 公户/私户账户 + **账户级授权**（授权人员/角色）+ **跨单据类型待付池 + 统一"去支付"** | **统一资金支付出口**（ZW 为单据内闭环） |
| 报销三向冲抵 | `报销总额 = 冲抵借款 + 冲抵备用金 + 报销余额`；`是否进行冲抵` 开关；明细可**跨项目** | 个人资金占用闭环 |
| 备用金/还款实时校验 | 表单加载即查个人备用金余额、未归还冲抵额、可还金额 | 防超额领用 |
| 产值统计 | 含 `累计材料使用量 / 现场存货 / 累计材料损耗率` | **工程量-材料-损耗联动** |

**07 卷同时给出 19 张资金单据的字段级清单**（必填/只读标记）、**17 个审批业务类型 ID** 与流程模型 ID、以及**单号规则**（SKDJ/ZJDZ/ZJDB/FKSQ/FYBX/BYJ/JKD/HKD/XZFF）。

**发现的竞品问题**：① 层"收入总额"（874.08 万）与 ③ 层"收入总额"（663.76 万）**口径不一致且系统内无说明**；`其他成本` 的 `budgetBalance` 实测为 **−85,500**（超预算不拦截）；`(合同+签证)金额` 在收入组与支出组**同名不同字段**；部分接口无数据时返回 `null` 而非空结构；**账户开立/资金到账/资金支付/资金筹备不走审批流**（而资金调拨/余额调整走审批）。

### 2.5 不可借鉴（反面清单，详见 06 卷）

编号规则不统一且可手改 · 合同闭合以"文件上传"为判据 · **招标日期无先后校验（实测开标日早于公告日）** · 预警默认未启用 · 附件阈值不一致 · 状态标签色义弱 · 字段名/文案遗留错误（`farming`/`pruchase`/`Inovice`）· 模板配置未清理（`cas.test.com` 残留）· 权限表含演示残留 · 行业特化模块（加工厂/铜铝价格/新能源）照搬 · 独立路由表单页范式迁移 · 代报价若无审计留痕。

### 2.6 资金与经营对标的结论（`08` 卷，最重要的一节）

把竞品与本项目 ZW-Insight 逐闭环比对后，**本项目不缺"深度"，缺"对称"与"最后一公里"**：

**还缺 6 个 P0 闭环**

| 缺口 | 本项目现状 | 后果 |
|---|---|---|
| **应付台账** | 应收有台账+FIFO 核销+账龄+双写不变量；**应付无对称台账**（散落两个 Mapper 求和） | 应付无账龄、无核销追溯、不可审计 |
| **在途额度占用** | 仅合同级两段（已结算−已付），**审批中的申请不占额度** | 可并发重复申请超额，资金内控漏洞 |
| **资金调拨闭环** | 有表 `biz_fund_transfer` + BPMN，但**无 REST Controller**、`submit` 直接置 APPROVED | 功能实际不可用 |
| **回款勾稽联动** | 付款侧勾稽驱动 `pay_status`；**回款侧勾稽无联动** | 双口径只在支出侧成立 |
| **统一支付出口** | 未发现（仅只读聚合） | 出纳需逐单 mark-paid，无待付池 |
| **无关联收付** | 付款 `contract_id NOT NULL` **硬禁止无合同付款** | 押金/零星/代垫无法入账 |

**另缺 11 个 P1**：客户/甲方维度分析（完全缺失）、三维主体台账、全公司合同执行汇总（现仅单项目）、资金构成分析（8 类饼图与趋势）、成本分析趋势与来源构成（`trends` 硬编码空列表）、实付成本维度（成本侧只有权责口径）、借款单/还款单、开票申请↔销项发票关联、进项发票↔采购订单额度占用、余额调整单、账户级授权与私户、多合同付款申请、工程量-材料-损耗联动台账。

**本项目的 10 项优势闭环**（竞品缺失，应固化进售前）：滚动资金预测（含 `overdue_unpaid` 构成项）、7 条风险规则 + 统一风险台账、应收台账（FIFO+账龄+双写不变量）、银行流水勾稽驱动支付态三档、票据/融资/四类保证金/工资专户/财务封账/税率/金额分级审批、资金日报 + 余额调节表、利润快照 + 归因 + 环比、**双口径文档化与不变量**、单据穿透下钻、月度经营分析（10 类落库快照）。
