## 一、一句话定位

**中经优采（天工工程云）是一个"双面市场 + 采购方 ERP"三位一体的工程采购平台**：

1. **供应商侧（需求侧获客）**：`www.zhongyoucai.com` 前台，全网标讯聚合（拟建/预告/招标/中标/招标信用信息）、项目直采、供应商免费注册入驻；
2. **采购方侧（供给侧付费）**：`/jeecgboot` 后的天工工程云 SaaS 管理端，是**一套完整的施工/安装企业项目管理系统**（28 个一级模块），采购寻源只是其中一环；
3. **平台侧**：运营方通过标讯聚合与信用信息为供应商导流，通过管理端向采购方收费，形成"**标讯引流 → 供应商入驻 → 采购方发标 → 平台撮合**"的闭环。

> 与广联达/新中大/建文等**纯管理软件**厂商的定位差异：中经优采是**管理软件 + 交易撮合平台**的混合体，与"云筑网/中铁鲁班网"（产业互联网平台）同族，但**同时具备完整的自建 ERP 能力**——这是它的独特性。

## 三、与 ZW-Insight 的相似度评估

### 3.1 可比性判定：**同赛道、强可比、互补性大于替代性**

| 维度 | 中经优采·天工工程云 | ZW-Insight | 判定 |
|---|---|---|---|
| 目标客户 | 施工/安装/新能源工程企业（光伏、机电为主，见项目名） | 施工总承包企业 | **一致** |
| 部署 | 多租户 SaaS（单库多租户） | 私有化/联调服务器 + 租户隔离 | **不同**（影响数据权限设计可比性） |
| 技术栈 | JeecgBoot + Vue3 + Flowable | Spring Boot 自研 + Vue3 + Flowable | **同源不同实现** |
| 业务主链 | 项目→预算(6类)→合同(收/支/其他)→采购寻源→订单→入库→结算→付款/收款→开票 | 项目→预算/CBS→合同→采购→材料→财务 | **高度一致** |
| 采购寻源 | **招标 12 节点 + 询价（物资/租赁/劳务/班组）+ 竞价（竞价/拍卖，起拍价+价格梯度）** | 询价→报价→评标→定标（**无竞价、无多轮**） | **竞品显著更强** |
| 成本归集 | **成本中心（实际成本/实付成本双口径 + 核实工作流 + 预算归集）** | CBS 成本账户 + 流水恒等 + 日对账 | **各有胜负** |
| 供应商协同 | **平台化外部协同**（供应商注册入驻 + 前台报价 + 黑名单/准入分级） | 供应商门户（`zw-supplier-portal`，询价/报价/我的报价） | **竞品更平台化** |
| 移动端 | 有微信小程序（页脚提及，未取证） | App（`zw-insight-app`，14 个页面模块） | `U` |
| 加工厂/生产 | **有完整加工厂模块**（销售订单→生产执行→进货→出库→成品入库→出门证→库存） | **无** | **竞品独有** |
| 铜铝价格 | **有**（价格分析，服务于电力设备/电缆成本） | 无 | **竞品独有** |
| 双口径资金 | 有（`costActual`/`costPaid`；`payStatus` 与 `status` 正交） | 有（`total_expense` vs `pay_status`） | **一致** |
| 逾期未付口径 | 未发现 | **有（单列 `overdue_unpaid`）** | **ZW 更强** |
| 限额领料 | 未发现 | 未发现 | 均无 |

### 3.2 关键差异（值得注意）

1. **竞品的"新能源"与"加工厂"是行业特化模块**：项目名多为"光伏电站""户用屋顶分布式"，配合"铜铝价格"与"加工厂"，说明其主打**电力/新能源安装工程 + 自建加工厂**的垂直场景，而非通用房建总承包。→ 对 ZW-Insight 的借鉴需做**行业剥离**（06 卷详述）。
2. **竞品的采购寻源深度显著超过 ZW-Insight**：这是本次逆向最有价值的部分（03/04 卷）。
3. **竞品缺少 ZW-Insight 的若干"经营级"能力**：滚动预测、逾期未付单列、CBS 流水恒等守卫、项目删除级联事件、防自审白名单。→ 这些应作为 ZW-Insight 的**护城河**写入售前材料。

### 3.3 相似度评分（0–5）

| 维度 | 分 | 依据 |
|---|---|---|
| 业务域覆盖重叠度 | **4.5** | 8 大域中 7 域高度重叠，仅"加工厂/生产"不重叠 |
| 目标客户重叠度 | **4.0** | 同为客户方工程企业，但行业侧重不同（新能源/电力 vs 通用房建） |
| 采购寻源重叠度 | **3.0** | 有询价与定标，但竞品多了招标 12 节点与竞价 |
| 技术架构可比性 | **4.0** | 同为 Flowable + Vue3，可逐机制对照 |
| **加权综合** | **4.1** | **第一层直接竞品**（与新中大/广联达同级） |

> 结论：中经优采应被列为 ZW-Insight 的**第一层直接竞品**，理由是采购寻源 + 成本归集 + 供应商平台化三项均为本产品强项，且行业垂直度与 ZW-Insight 相邻。
