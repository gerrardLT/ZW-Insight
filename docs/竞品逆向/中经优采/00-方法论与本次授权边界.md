## 一、本卷证据规范相对"纯公开语料取证"的修订（必须先读）

**纯公开语料取证**的合规底线是"**不登录未授权租户、不抓取私有接口**、不复刻受版权保护的表达、看不见就不写"——那是只靠公开材料做逆向时的红线。

本卷情况不同：**目标系统账号由用户（账号持有人）主动提供并明确授权**，取证方式从"公开语料"升级为"**授权的只读运行时观察**"。因此：

| 维度 | 纯公开语料取证 | 本卷（授权只读运行时） |
|---|---|---|
| `source_role` | `official_documentation` / `vendor_claim` / `third_party_report` | **`runtime_observation`（最强）** / `ui_observation` |
| `provenance_grade` | 多为 P2–P4 | **P4**（原始发布者=被测系统自身；时间/版本/身份可定位） |
| `claim_fit` | 多为 F1–F3 | **F3**（直接展示当前断言） |
| 主要风险 | 把招标要求当产品能力 | **把"本租户配置"当"产品能力"**；把"UI 可见"当"服务端已校验" |

### 本次授权边界（用户于 2026-10-10 明确答复）

1. **允许**用该账号登录，并**只读遍历全站**（浏览、翻页、开详情、看弹窗）。
2. **禁止**新建 / 修改 / 删除 / 提交任何业务单据；**禁止**触碰其他租户数据。
3. 覆盖视角：**采购方**（`/purchasehome` 工作台）、**供应商/投标方**、**平台运营/管理后台**。

> 本次实际执行严格遵守：全程未发起任何 `POST/PUT/DELETE` 写业务数据的请求；唯一"写"动作是登录（`POST /sys/login`）。
> 所有批量取数走 `GET` 只读接口，参数仅分页与筛选。

### 凭证处置

账号与口令由用户持有，**不写入本卷任何文档**。下文以「用户授权账号（管理员角色，所属项目部）」指代。

## 三、取证方法（可复现）

本卷证据来自四条独立取证链，互相印证：

| 链 | 方法 | 产出 | 蒸馏产物 |
|---|---|---|---|
| **A. 静态考古** | 抓取入口 bundle 与 118 个业务分片，解码 `\uXXXX`，正则抽取接口/中文文案 | 203 条接口路径；953 个懒加载分片名（612 唯一组件）；1481 条中文 UI 文案 | `附录A` A.1/A.3；04 卷 §三 |
| **B. 权限枚举** | 登录后调 `GET /sys/permission/getUserPermissionByToken` | 全站菜单树（309 节点）+ 38 个按钮级权限码 + 字段级权限 | `附录A` A.4；04 卷 §一 |
| **C. 运行时遍历** | Playwright 多页批量扫掠，抽取每页 面包屑/页签/筛选/按钮/表头/真实行数据 + 该页 XHR | 30 个页面摘要、6 个表单字段清单（含必填/只读标记） | 本卷 02–05 |
| **D. 只读取数** | 以授权 token 直调 17 个列表/详情接口 | 真实字段名 schema + 真实状态值 + 真实业务数据 | 本卷 02/03 |
| **E. 状态机取证** | `GET /epp/tender/{id}/node` | 招标 12 节点完整序列 + 三态 + 用时 | 03 卷 §2.2 |

> **中间产物处置**：链 A–E 的原始抓取物（bundle、分片、权限/字典/接口响应 JSON）为**本次会话临时产物**，按项目约定（AGENTS.md §9）已于任务结束即清理；其**蒸馏结果**已全部落盘至本目录各分卷与 `附录A`，可脱离原始抓取物独立复核。

> **方法说明**：链 D 之所以可行，是因为实测发现**权限接口只校验 `x-access-token`，不校验 `x-sign`**（`x-sign` 缺失时仍返回 `code:0`）。这是 JeecgBoot 默认鉴权强度，本卷据此批量取数，未做任何绕过或破解。

## 四、粒度与"看不见"的边界（诚实声明）

本卷证据强度**高于**纯公开语料逆向稿（后者受限于公开语料，界面级细节普遍缺失），但仍有三处硬边界，凡涉及处均已标 `U`：

| 边界 | 说明 | 影响 |
|---|---|---|
| **E1. 未执行写操作** | 授权为只读，故**未**实际触发"提交→审批→驳回→回写"链条 | 状态机的**状态值域**（`statusValue`/`serviceStatusCn` 等）与**节点序列**为实证；但**迁移的触发动作与前后置校验**多为 `H`（由按钮文案+表单必填+状态值域推断）或 `U` |
| **E2. 无供应商账号** | 仅有采购方账号，供应商侧工作台（报价、投标、我的中标）**未登录观察** | 供应商侧页面结构来自**前端分片与公开路由**（`P4/F3`），其**登录后行为**标 `U` |
| **E3. 本租户业务数据为空** | 询价管理、竞价拍卖两模块本租户记录数 = 0 | 询价/竞价的**列表结构与表单字段**为实证；其**真实业务数据与完整流转**标 `U`（状态词表来自 UI 文案，非数据） |

另：移动端（App/小程序）**未取证**——平台前台页脚提到"微信小程序"，但未观察其形态，标 `NOT_FOUND`。

## 五、负面结论四分类（本卷实际用到）

```
EXPLICITLY_ABSENT  本次未使用（无"明确不支持"级证据）
NOT_FOUND          在本次取证范围（静态 bundle + 授权租户运行时）内未发现
```
