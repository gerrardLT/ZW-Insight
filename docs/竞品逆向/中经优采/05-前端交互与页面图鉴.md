## 二、列表页统一范式（`E`，24 个页面实测一致）

```text
[面包屑] 采购管理 / 采购订单
[页签]   采购订单                      ← 单页签（多子类时并列，如询价 4 页签、供应商 7 页签、预警 5 页签）
[筛选区] 采购订单名称 [___] 项目 [v]  [查 询] [重 置]
[工具栏] [导出] [展开] [新 增] [字段设置] [修订]
[表格]   审批状态|项目|标题|单号|...|操作
[行操作] 查看 / 修订 / 删除 / 编辑
```

**统一特征（`E`）**：

| 元素 | 统一形态 |
|---|---|
| 查询按钮 | **`查 询`**（中间带全角空格）与 **`重 置`** —— 全站一致的写法，属该产品"视觉指纹" |
| 工具栏按钮 | `导出` / `展开`（展开筛选）/ `新 增` / `字段设置` / `修订` / `删除` |
| **字段设置** | **列表列可自定义显示**（本产品普遍提供，`E`） |
| 行操作 | 文字按钮（`查看`/`修订`/`删除`/`编辑`），非图标 |
| 状态列 | 统一置于**第一列**（"审批状态"），且用标签渲染 |
| 空态 | `暂无数据`（ant 默认） |
| 分页 | 采购类 `pageSize=50`，结算/竞价类 `pageSize=10`（**不统一**，`E`） |

> **观察**：`字段设置`（自定义列）+ `导出` 是**每个列表页的标配**，说明产品定位偏向"**台账导出型使用**"（工程企业习惯导出 Excel 汇报）。

## 三、状态标签色义（`E`，实测 RGB）

| 状态文本 | 标签类 | 文字色 | 背景色 | 语义 |
|---|---|---|---|---|
| `审批通过` | `ant-tag-success` | `rgb(85,209,135)` | `rgb(240,255,243)` | 成功（绿） |
| `正常` | `ant-tag-has-color` | `#fff` | **`rgb(7,193,96)`（实心绿）** | 有效（实心绿） |
| 招标节点（`开评标`/`标前准备`/`招标文件`/`招标计划`/`中标通知`） | `ant-tag-processing` | `rgb(57,112,227)` | `rgb(240,247,255)` | **进行中（蓝）——所有节点同色** |
| 供应商状态（`已生效`/`合格供应商`/`试用`） | `ant-tag-default` | `rgba(0,0,0,.85)` | `rgb(250,250,250)` | **默认（灰）——所有档位同色** |
| 项目名/标题等标签 | `ant-tag` / `ant-tag processing` | 黑 | `rgb(250,250,250)` | 中性（非状态） |

### 色义评估（`E` → 结论）

**本产品的状态色义只有 3 种有效语义**：成功=绿 / 进行中=蓝 / 默认=灰。

**关键缺陷（`E`）**：
1. **招标 12 个节点全部用蓝色 `processing`**——包括已完成的"中标通知"与未开始的"招标计划"，**颜色不表达节点进度**（进度信息只在"当前节点"文本里）。
2. **供应商 7 档准入全用灰色 `default`**——`合格`/`试用`/`战略供应商`/`黑名单` 无颜色区分，**风险等级不可视**。
3. **未见 `warning`（橙）/ `error`（红）色**用于业务告警——审批驳回、流标、黑名单等**高风险状态未用红色**。

> **对照 ZW-Insight**："状态标签颜色语义 + 状态×操作矩阵"是 ZW-Insight 的既有优势项。本产品在此项**明显弱于** ZW-Insight。→ 06 卷列为"ZW 优势，应固化"。
