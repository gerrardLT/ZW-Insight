财务管理覆盖资金的"收—支—结—管—析"全链路：收入侧确认回款并自动核销应收，支出侧按可付上限控制付款，结算封账锁定账期，资金管理与经营分析提供集团级资金视图、招待费异常监控与月度 10×6 经营矩阵。

> 入口：**财务管理** 菜单（路由前缀 `/finance/*`），共 28 个功能页。下文按"收入与应收 / 支出与报销 / 结算封账 / 资金管控 / 经营与专项分析 / 基础配置"分组说明。

## 资金流转全景

```mermaid
flowchart LR
  收款[回款登记 甲方付款] --> 池[(项目资金池)]
  池 --> 付款[付款申请 支出合同]
  池 --> 工资[工资专户拨付]
  池 --> 保证金[保证金缴纳/退还]
  开票[开票申请] --> 收款
  结算[项目最终结算] --> 封账[财务封账]
  付款 -.累计已付.-> 支出[项目总支出]
  收款 -.累计收款.-> 收入[项目总收入]
  支出 --> 垫资{{垫资 = 总支出 − 总收款}}
  收入 --> 垫资
```

- 开票/回款都必须挂接**已生效的施工合同**；只有审批通过才回写累计值，删除已生效单据会对称冲销。

### 付款申请（核心，字段级）

![付款申请列表](./images/finance/payment-apply.png)

新增付款申请表单字段：

| 字段 | 必填 | 说明 |
|---|---|---|
| 项目 | 是 | 付款所属项目 |
| 合同类型 | 是 | 决定路由到哪张合同表（采购/劳务/机械/分包/其他） |
| 关联合同 | 是 | 先选项目与合同类型后才可选 |
| 收款单位 | 是 | 供应商/班组/分包单位 |
| 付款金额 | 是 | 受"可付上限"校验（见下） |
| 付款日期 | 是 | — |

![新增付款申请弹窗](./images/finance/payment-form.png)

**可付上限（权威口径）**：

```
最大可付金额 = 合同累计结算 + 净奖惩 − 合同累计已付
```

- 付款金额 > 上限即被拒，提示"付款金额不能超过（累计结算含奖惩）减已付金额，最大可付金额：X"。
- **净奖惩**（奖励为正、处罚为负）仅**劳务/分包**合同适用，其它类型计 0。
- 付款按合同类型路由到对应合同表读取累计值；OTHER 类别走"其它合同"。
- **提交时**回填"累计结算快照/未付金额快照"到单据，供详情追溯；**审批通过（onApproved）时**才回写合同累计已付与项目总支出，且生效前会**重新校验**可付上限（审批期间额度若变化会超限自动驳回）。
- **金额分级审批**：付款金额命中「审批分级配置」（`/system/amount-tier`）的档位时，流程按 `approvalTier` 路由到更严的审批节点。

## 关键校验与规则

- **双口径严格区分（2026-09-23 强制规范）**：
  | 口径 | 核心字段 | 业务含义 | 消费场景 |
  |---|---|---|---|
  | **审批口径** | `biz_project.total_expense` | 付款申请**审批通过时点**即回写 | 项目总支出、月度计划实际支出回填、R7 审计基线、已实现利润计算 |
  | **现金口径** | `biz_payment_apply.pay_status` / `pay_date` | 银行流水勾稽足额或手工确认后标记为 `PAID` | 滚动资金预测付款侧、待支付大额支出 TOP、驾驶舱「已批未付」卡 |
  - **不变量守卫**：`pay_status` 任何状态变更**绝不重复回写** `total_expense` 或合同累计已付，避免造成账实不一致。
- **回写只在生效时点**：付款/回款/开票审批通过才回写合同累计值与项目总收支；删除已生效单据对称冲销。
- **可付上限 = 累计结算 + 净奖惩 − 累计已付**；付款生效前二次校验，超限自动驳回并通知发起人。
- **封账保护**：封账期间内财务单据不可新增/修改，需先解封。
- 金额统一 `DECIMAL(18,2)`；所有累计值均需有真实业务单据支撑，受自动化数据审计严密监控。

## 常见问题

**Q：付款申请提示超出可付金额？**
A：确认该合同是否已有足额"已审批结算"。可付上限 = 累计结算 + 净奖惩 − 累计已付；没结算就没额度。

**Q：项目总支出是实际划款金额吗？**
A：不是。`total_expense` 是「审批口径」——在付款申请审批办结时即生效回写，用于反映已确立的支出责任；真实现金划出由 `pay_status=PAID` 表达。两者分工明确，不得混淆。

**Q：为什么"其他费用付款"没算进项目总支出？**
A：项目总支出统一由付款申请（对五类主线支出合同）与资金调拨回写；其他费用付款单列在"其他付款"，不并入项目主线总支出，避免口径混淆。
