项目是全部业务的"根"：合同、预算、产值、结算、付款都挂在项目下。本章讲项目的创建、状态流转、成员与 WBS 分解。

> 入口：**项目管理 › 项目报备**（`/project/list`）；WBS 在 **项目管理 › WBS结构**（`/project/wbs`）。

## 项目列表与状态流转

![项目报备列表](./images/main-flow/project-list.png)

列表检索条件：项目名称 / 状态 / 项目类型。表格列：项目编号、项目名称、项目性质、项目类型、业主单位、签约公司、状态、创建时间、操作。

行内操作随状态变化：

| 操作 | 可用状态 | 说明 |
|---|---|---|
| 查看 | 全部 | 打开项目详情（合同/产值/财务汇总/成员） |
| 编辑 | DRAFT | 仅草稿可改 |
| 提交 | DRAFT | 提交立项，进入后续阶段 |
| 删除 | DRAFT | 受引用与级联约束（见下） |
| 结项 | 施工中/已竣工 | 发起结项，生成最终结算单 |

## 新增/编辑项目（字段级）

表单字段：项目名称、项目编号（系统生成）、项目性质、项目类型、业主单位、签约公司、联系人、联系电话、项目概述、项目地址、预算金额、是否招标。保存为 `DRAFT`。

## 项目成员

项目详情内可维护成员：选择用户 + 项目角色；列表列：姓名 / 部门 / 项目角色 / 加入时间 / 操作（变更角色、移除）。

## WBS 工作分解

![WBS结构](./images/project/wbs.png)

为项目建立工作分解树。节点字段：父节点、节点编号、节点名称、描述、计划工期、排序。操作：新增根节点 / 加子节点 / 编辑 / 删除。

## 关键校验与规则

- **仅 DRAFT 可编辑/删除/提交**；提交后进入立项流转，不可再改。
- **存在投标报名引用的项目不可删除**（引用拦截）。
- **删除项目是级联删除**：同步清理该项目下 69 张关联表（合同、结算、付款、库存等），不可恢复——删除前务必确认。
- **WBS 节点删除受子节点守卫**：有子节点时须先删子节点。

## 常见问题

**Q：为什么"删除"按钮是灰的 / 删除报错？**
A：项目不是 DRAFT，或已有投标报名引用。前者需先撤回流程，后者不允许删除（可走结项归档）。

**Q：结项和删除有什么区别？**
A：结项是业务闭环（生成最终结算单、状态置 COMPLETED/CLOSED，数据保留可查）；删除是物理级联清除，数据不可恢复。正常完工用结项，绝不用删除。
