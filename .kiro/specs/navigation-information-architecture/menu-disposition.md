# 菜单处置表

本表针对原 114 个可见叶级菜单。此次仅改变导航呈现，不删除路由、页面、API 或权限码。

## 工作台 / 经营分析
- 首页：保留工作台主入口。
- 项目看板：归经营总览，项目经理快捷入口。
- 成本主线看板：归经营总览，与成本中心共同分组，不删除页面。
- 经营总览、资金中心、风险中心、项目经营、成本中心：归经营分析。
- 财务资金看板：退出核心入口，与资金中心同组；旧 URL 保留。
- 招待费分析：作为成本分析下钻入口。
- 月度经营分析：归经营分析。

## 项目经营
- 项目报备：保留，展示名仍沿用现状。
- WBS结构：归项目管理分组，后续宜降为项目详情入口。
- 投标报名、证件管理：归项目经营。
- 施工合同、产值上报、变更事件：归合同管理；后两者后续宜进入合同上下文。
- 预算编制、目标成本变更、预算控制配置、成本账户CBS：归成本履约；控制配置为低频设置。

## 成本履约 / 现场生产
- 采购合同、采购结算、询价比价：保留同一采购分组。
- 劳务合同、班组、花名册、用工单、工资单、薪资统计：归劳务履约；班组+花名册、工资单+统计为后续 Tab 候选。
- 到货入库、领料出库、材料调拨、库存查询、退货退款：归材料库存；退货为次级作业。
- 机械合同、机械台账、进出场、台班/工作量、故障维修、机械结算：归机械履约。
- 分包合同、分包结算：归分包履约。
- 进度计划、施工日志、质量安全检查：归现场生产。

## 财务资金
- 开票申请、收票登记、发票汇总：同组；后续合为发票管理 Tabs。
- 回款登记、应收台账、质保金管理：收入与应收。
- 付款申请、其他费用付款、项目报销、备用金、个人报销：支出与报销；后三类为 Tabs 候选。
- 项目最终结算、财务封账：独立高风险动作，保留。
- 税率、资金分类科目、账户分组：低频财务设置。
- 保证金、工资专户、票据、融资：专项资金台账候选。
- 资金计划：保留高频入口。
- 银行流水、余额调节表、资金日报：银企对账作业链。

## 资源档案
- 档案查询：保留统一入口。
- 其它收入合同档案、其它支出合同档案、办公用品档案：降为档案分类入口，旧 URL 保留。
- 材料字典、供应商、甲方单位、自持公司、检查方案、供应商评价、供应商黑名单：归基础数据；供应商三页为聚合候选，检查方案为现场配置候选。

## 协同办公
- 人事统计、入职、办公用品、车辆、离职：行政人事分组。
- 流程设计器、流程定义、业务类型、审批管理、审批回滚：工作流分组；回滚继续独立高风险入口。
- 通知、公告：内容发布聚合候选。
- 推送渠道配置：低频通知设置。
- 消息中心：保留顶栏铃铛和搜索入口。

## 平台治理
- 机构、人员、角色、菜单、字典、岗位、系统设置：配置入口。
- 模板、打印模板：模板中心聚合候选。
- 日志、审批分级、编号规则、备份、版本：管理员/运维入口。
- 系统监控：页面为空壳，暂时从导航隐藏，路由保留。
- 租户、用户类型、存储：平台超管入口。

## 回滚
删除或回滚 `DefaultLayout.vue` 的双栏导航消费、`NavLink.vue` 与 `utils/navigation.ts`，恢复旧 `menuRoutes` 渲染即可。localStorage 的 `zw-nav-favorites:*`、`zw-nav-recent:*` 无服务端副作用，可忽略或清除。
