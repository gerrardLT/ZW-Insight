# 财务清晰化 / 工程术语 / 前端契约 改造需求

> 立项日期：2026-10-18 ｜ 依据：三轮探查（项目管理对标中经优采、术语与项目财务清晰化、前端交互对照）+ 用户已批准实施计划
> 竞品参照：`docs/zhongyoucai/`、`docs/竞品逆向/中经优采/`、`docs/竞品逆向/中经优采-v2/`

## R1 术语与菜单（用户不满点 1）

1. 菜单名一律为单据/台账名词（对象名），不带动作词与"管理"后缀；同一概念全站一个名字。
2. 状态显示名贴中国工程惯例：已报备→已立项、招标中→投标中（承包人视角）、已中标→待开工、已落标→未中标、施工中→在建、已暂停→停工、已关闭→已结项；**仅改显示层，DB 枚举值与状态机不动**。
3. `projectNature`/`projectType` 等枚举字段统一走字典（本轮先落标签常量层与术语表，字典化在阶段三扩展）。
4. 术语基准唯一源：`docs/术语表.md` + `zw-insight-web/src/constants/biz-labels.ts`；模板内禁止手写状态映射；`check-labels` 脚本 warn-only 防退化。

## R2 菜单组织（财务域 28 项平铺问题）

1. 财务资金域内按 meta.group 分为：收入 / 支出 / 发票税务 / 资金 / 专项 / 分析 / 治理 七组，前端 section 化，不改 sys_menu 结构与路径（方案 A）。
2. 菜单改名只 UPDATE menu_name（不动 id/path/权限），迁移双轨幂等；角色绑定沿用既有 NOT EXISTS 守卫，绑定一律按 `sys_role.role_code` 查 id，防双机角色 id 分叉。
3. `keys/check-menu-coverage.cjs` 保持 exit 0。

## R3 钱链可见（用户不满点 2）

1. 施工合同列表展示六段收入链：合同额→签证→产值→结算→开票→回款→未收（未收=合同额+签证−累计回款），金额列右对齐千分位 + 本页汇总行（标明非全量）。
2. 五类支出合同列表展示四段：合同额→累计结算→已付→应付未付。
3. 项目详情提供"项目经营"入口（阶段二临时嵌驾驶舱组件，阶段三换 onebook 聚合端点）。
4. 分包结算生成正式结算单编号（serial_number_rule），列表禁止展示数据库 ID 当单号。

## R4 应付侧对称（最大功能缺口）

1. `biz_payable` + `biz_payable_write_off` 台账，对称应收：五类支出合同结算审批通过幂等生成（金额=结算−已付，≤0 不生成）；付款审批通过 FIFO 核销 + 逐笔明细 + 可反冲；账龄五桶；`biz_project.payable_amount` 同事务双写不变量。
2. 存量回填幂等可重跑，来源=既有 `ContractPayableMapper.sumPayableOutstanding`（合同粒度转台账粒度）。
3. 付款在途占用：`SUM(SUBMITTED)` 聚合；付款额度校验升级为"已申请+申请中+本次 ≤ 累计结算+净奖惩−已付"硬拦截；列表加"已申请/申请中/可申请"三列。

## R5 前端契约（标配化打法）

1. 三张契约：ZwListPage（列表五件套：字段设置/导出/展开筛选/汇总行/刷新 + 状态首列 ZwStatusBadge + 空态/骨架/密度/键盘行导航 + 分页 20/50/100）、ZwFormPane（分区+锚点导航+暂存/提交+审批区+派生只读样式）、ZwDetailDrawer（行内详情）。
2. 换壳只动模板层，不改 `api/*.ts` 路径与后端契约；一致性审计 Critical 保持 0。
3. 启用闲置组件 ZwStatusBadge/ZwTableDensitySwitch/ZwFormAffixNav；键盘行导航抽 `useRowNavigation` composable 去重 4 处内联。
4. 首页加"今日工作台"行（待办/已办/我发起/未读计数，复用既有接口）。

## R6 明确不做（范围外，后续立项）

多合同付款、统一待付池、无关联收付、借款/还款单、客户/供应商维度台账、菜单嵌套路由化授权改造（方案 B）、DB 状态枚举值改名、移动端改造。

## 强制边界

- 不运行本地 Java/mvn（后端验证走 CI/服务器）；push 与部署须用户确认；双机差异按 AGENTS.md 纪律。
- 迁移双轨镜像（migration + db-init NN_）、幂等、MySQL 8 兼容；下一版本号 V2026_113 起。
- R7 审计基线不破：新增累计值（payable_amount）必须有单据支撑，种子不写死。
- 测试受阻即登记 tasks.md 受阻项登记表，禁止静默降级与假数据。
